# Catálogo de Válvulas — Vexbiz Suministros

Catálogo digital de válvulas Bray, Ritepro y Dorot (16 productos), sin precios.

## Cómo usarlo
- Abrir `index.html` en el navegador, o publicar la carpeta con GitHub Pages.
- Navegación: botones **Anterior / Siguiente**, botón **Ver índice**, flechas del teclado o deslizar el dedo.
- Cada página tiene su propio enlace: `index.html#p5` abre la página 5.

## Archivos
- `index.html` — el catálogo completo (HTML, CSS y JS en un solo archivo).
- `img/` — fotos de producto tomadas de los catálogos oficiales de cada fabricante.
